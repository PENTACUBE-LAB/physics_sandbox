## Physics Sandbox

**An experimental computational physics environment for exploring coupled physical systems.**

Physics Sandbox is an independent research and development project focused on computational physics, numerical simulation, and interactive exploration of theoretical models.

### Project Overview

Physics Sandbox provides an interactive environment for exploring mathematical models and observing the numerical behavior of coupled physical systems through configurable simulation parameters.

### Current Capabilities

- Numerical simulation using Python.
- Spectral methods and Fast Fourier Transforms (FFT).
- Runge–Kutta 4 (RK4) time integration.
- Poisson equation solver.
- Interactive parameter controls and visualization.
- Diagnostic monitoring and simulation benchmarks.

### Research Scenarios

The current prototype includes exploratory scenarios involving:

- Boson star configurations.
- Aharonov–Bohm effects.
- Rashba spin-orbit coupling and vortices.
- Klein tunneling.
- Majorana-related modes.
